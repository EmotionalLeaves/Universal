# Universe Explorer

An Android app for flying through the whole universe in 3D — from the edge of the observable universe down to the ground of a single planet. Real catalog data wherever it exists; repeatable generated data everywhere else.

**Download:** grab the newest APK from [Releases](../../releases/latest) and install it over the old one.

- Build plan: [`docs/PLAN.md`](docs/PLAN.md)
- Progress by round: [`docs/PROGRESS.md`](docs/PROGRESS.md)

Every push to `main` builds a signed APK with GitHub Actions. No computer needed.

Code: MIT. Data credits are listed in the plan and, later, in the app's Credits screen.
